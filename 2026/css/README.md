### Tailwind CLI Guide

1. Install Node.js  
   Download and install: https://nodejs.org/en/download

2. Go to your project folder.

3. Open Terminal or CMD and make sure you are in the correct project directory.

4. Run the command below to install Tailwind:
#####
        npm install tailwindcss @tailwindcss/cli

5. After installation, start the compiler with:
#####
        npx @tailwindcss/cli -i ./css/input.css -o ./css/output.css --watch
